# Unemployment Analysis with Python

## Project Description
This project analyzes unemployment trends in India using Python. The analysis includes data cleaning, visualization, regional comparison, and unemployment trend analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Features
- Data Cleaning
- Data Visualization
- Regional Analysis
- Urban vs Rural Analysis
- Monthly Trend Analysis

## Dataset
Unemployment in India Dataset
